# Dialogs and Feedback

This topic is now split by whether feedback interrupts the user:

- [Dialogs and Context Menus](./dialogs) — alerts, confirmations, prompts,
  focus, modality, and temporary action menus.
- [Feedback and Progress](./feedback-and-progress) — inline status, Toast
  notifications, ProgressBar, and scheduled work.

## Quick Choice

Use inline status for persistent information, Toast for temporary
notifications, ProgressBar for measurable work, and Dialog only when the
answer changes what happens next.

Continue with [Feedback and Progress](./feedback-and-progress) for ordinary
application feedback or [Dialogs and Context Menus](./dialogs) for decisions.
