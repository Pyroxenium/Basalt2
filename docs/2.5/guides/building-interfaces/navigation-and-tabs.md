# Navigation and Tabs

Navigation is now covered in two focused guides:

- [Page Navigation](./page-navigation) — persistent application pages,
  sidebar routes, active styling, and destination focus.
- [Tabs](./tabs) — related views inside one TabControl.

## Quick Choice

Use page Frames for major destinations such as Dashboard, Jobs, and Settings.
Use Tabs for related views inside one destination. The two patterns can be
combined without rebuilding their contents.

Start with [Page Navigation](./page-navigation), then add [Tabs](./tabs)
where one page needs several closely related panels.
