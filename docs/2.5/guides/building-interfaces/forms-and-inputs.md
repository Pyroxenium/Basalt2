# Forms and Inputs

The form material is now split into two shorter guides:

- [Text Inputs](./text-inputs) — Input, TextBox, editing events, Enter, and
  focus progression.
- [Form Controls and Validation](./form-controls-and-validation) — Checkbox,
  Switch, Slider, reactive form values, validation states, and submission.

## Quick Choice

| Need | Control |
| --- | --- |
| One line of text | Input |
| Multiline editing | TextBox |
| Boolean choice | Checkbox or Switch |
| Numeric range | Slider |
| Fixed compact choice | Dropdown |
| Editable choice with suggestions | ComboBox |

Start with [Text Inputs](./text-inputs), then combine controls and state in
[Form Controls and Validation](./form-controls-and-validation).
